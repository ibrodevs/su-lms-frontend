# Bilim Ordo

Static prototype prepared for Vercel.

## Local preview

```powershell
npm install
npm run preview
```

Open the URL printed by `serve`.

## Deploy to Vercel

```powershell
npm install
npx vercel
```

For production:

```powershell
npx vercel --prod
```

The deploy entry point is `index.html`. The original exported file is kept as `Bilim Ordo.dc.html`.
